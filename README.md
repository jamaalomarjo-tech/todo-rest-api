# Todo REST API

Student backend project built with Node.js, Express, MySQL and Sequelize.

## Features
- User registration and JWT authentication
- Todo and category endpoints
- Swagger API documentation
- Automated tests using Jest and Supertest

## Setup
1. Run `npm install`.
2. Copy `env_example` to `.env` and set your own local MySQL credentials and JWT secret.
3. Create the local database and run `npm start` (see `package.json` for scripts).

This is a student project and is not intended for production deployment.
